# Freeder

Freeder — это современное, многофункциональное приложение для чтения, созданное с использованием Flutter. Оно разработано, чтобы помочь пользователям усваивать текстовый контент быстрее, эффективнее и с большей концентрацией.

## 🚀 Работает на базе технологии RSVP

В самом сердце механизма чтения Freeder лежит бесшовная интеграция технологии **быстрого последовательного визуального предъявления (RSVP)**. RSVP — это научно доказанный метод, который отображает слова последовательно, одно за другим, в фиксированной фокусной точке на экране. 

Благодаря полному использованию встроенной логики RSVP, Freeder предлагает:
*   **Устранение саккад:** предотвращая физическое сканирование глазами по строкам и страницам вниз, RSVP значительно снижает утомляемость при чтении и напряжение глаз.
*   **Настраиваемая скорость (Слов в минуту - WPM):** Идеально подстройте скорость воспроизведения под ваш уровень комфорта. Читаете ли вы в неспешном темпе или используете скорочтение со скоростью более 800 слов в минуту, механизм RSVP адаптируется к вашим потребностям.
*   **Улучшенное понимание:** Погружение в одну фокусную точку для каждого слова заставляет глубоко концентрироваться, снижая вероятность отвлечения мыслей и фактически увеличивая запоминание информации.

## ✨ Основные функции и логика

Помимо механизма RSVP, Freeder оснащен множеством инструментов для управления и настройки вашего процесса чтения:

*   **Импорт локальных файлов:** Легко просматривайте и импортируйте собственные документы и текстовые файлы прямо из памяти вашего устройства с помощью удобного средства выбора файлов (`file_picker`).
*   **Надежная локальная библиотека:** Все импортированные вами книги, прогресс чтения и закладки безопасно хранятся в автономном режиме с использованием легкой и высокопроизводительной базы данных SQLite (`sqflite`).
*   **Интуитивно понятный UI/UX:** Высокоинтерактивный пользовательский интерфейс, включающий современные выдвигающиеся панели (`sliding_up_panel`) и потрясающие внутренние тени (`flutter_inset_box_shadow`), что делает навигацию невероятно простой.
*   **Сохранение настроек:** Ваши конфигурации чтения, темы и скорости RSVP сохраняются локально (`shared_preferences`), гарантируя, что ваша персонализированная среда готова каждый раз, когда вы запускаете приложение.
*   **Реактивное управление состоянием:** Под капотом Freeder опирается на экосистему GetX (`get`) для высокореактивного управления состоянием и маршрутизации.

## 🛠️ С чего начать

Эти инструкции помогут вам запустить копию проекта на вашем локальном компьютере для целей разработки и тестирования.

### Предварительные требования

*   Flutter SDK (Версия 3.9.0 или выше)
*   Dart SDK
*   IDE, такая как Android Studio, IntelliJ IDEA или VS Code с установленными плагинами Flutter.

### Установка для программистов

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/freeder_new.git
   cd freeder_new
   ```

2. **Установите зависимости:**
   ```bash
   flutter pub get
   ```

3. **Запустите генерацию кода (если применимо для локализации/splash-экранов):**
   ```bash
   flutter pub run flutter_native_splash:create
   flutter pub run flutter_launcher_icons
   ```

4. **Запустите приложение:**
   ```bash
   flutter run
   ```

## 📚 Создано с использованием

*   Flutter - Используемый UI-фреймворк.
*   GetX - Управление состоянием и маршрутизация.
*   Sqflite - Локальное хранилище базы данных.
*   [RSVP Engine] - Пользовательская логика быстрого последовательного визуального предъявления для оптимального скорочтения.
